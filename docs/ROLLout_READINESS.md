# Release readiness

Актуально на 2026-04-22.

## Минимальный чеклист

- Backend запускается на `5001`.
- Frontend запускается на `5173`.
- `prisma:migrate:deploy` применён.
- `prisma:seed` выполнен или справочники созданы вручную.
- `smoke:servicedesk` зелёный.
- `smoke:merge-approval` зелёный.
- `email:smoke` зелёный.
- `backup:create` и `backup:list` зелёные.
- На сервере включён `BACKUP_ENABLED=true`, если backend будет работать постоянно.
- Для реального email-пилота заполнены `EMAIL_IMAP_USER` / `EMAIL_IMAP_PASSWORD` и проверен `email:sync`.
- `frontend lint/build` зелёные.
- Пользователь создаёт заявку через UI.
- Админ редактирует справочники через UI.
- Вложение загружается и скачивается.
- Merge/close approval работает из UI.

## Кого подключить к приёмке

- Директор.
- 1С аналитики.
- 1С разработчик.
- Системные администраторы.
- Представитель склада.
- Пользователь, который раньше работал во Freshdesk.

## Что показать

1. Создание заявки обычным пользователем.
2. Настройка папки и типа администратором.
3. Обработка заявки исполнителем.
4. Комментарии и вложения.
5. Объединение дублей.
6. Статистика на dashboard/reports.
7. Ручной backup перед началом пилота.
8. Создание заявки из тестового email.
