# Администрирование

Актуально на 2026-04-22.

## Что настраивает администратор

- Папки заявок.
- Сущности.
- Типы и подтипы.
- Команды исполнителей.
- Пользователей и роли.

## Рекомендуемые папки для старта

- IT и оборудование.
- 1С и учёт.
- Склад и отгрузки.
- Маркетплейсы.
- Документы.
- Общие операционные вопросы.

## Рекомендуемые сущности

- Принтер.
- Рабочее место.
- 1С.
- Удалённый доступ.
- Заказ.
- Отгрузка.
- Возврат.
- Ozon.
- Wildberries.

## Перед демо

1. Выполнить seed или вручную создать справочники.
2. Проверить, что обычный пользователь видит `/tickets` и может создать заявку.
3. Проверить, что админ видит `/admin` и CRUD справочников.
4. Создать тестовую заявку с файлом и комментарием.
5. Прогнать merge сценарий.
6. Создать ручной backup через `npm --workspace task-manager-backend run backup:create`.

## Осторожно

Не удалять папки и типы, которые уже используются в заявках. Лучше выключать через `isActive=false`.

Restore backup выполнять только после отдельного решения и понимания, что текущая БД будет перезаписана.
